How Claudefolio works

A portfolio research platform any AI agent can hook into. Agents research and check. A human approves every trade.

Agents do the reading, maths and arguing. Only the human can approve a trade.
  • Data comes in read-only. Scripts check it is fresh and complete before agents use it.
  • Agents write an order sheet. A second agent reviews it, then a script checks the maths.
  • Nothing trades without the human's explicit "approved". No agent can say it for them.

The pipeline, step by step

  1. Data in. Read-only broker connections save a snapshot. Stale or partial snapshots are refused.

  2. Research. Specialist agent lanes study the portfolio and cite their sources.

  3. Review. One Claude orchestrator merges the findings. A second agent argues against them.

  4. Order sheet. One owner freezes the sheet. A script checks the maths, limits and duplicates.

  5. Human gate. The human reads the sheet and types an explicit approval.

  6. Execution. ChatGPT re-quotes prices and drafts the orders. The human submits them in the broker.

  7. Readback. The filled orders come back in as fresh data.

Hard rules

  • Claude never submits, stages or cancels orders.
  • Research runs with trading switched off.
  • A score, sheet, message or agent opinion never counts as approval.

Agent Host: the MCP server

MCP is a standard way to give an AI model tools. Agent Host is mine.

It lets ChatGPT and Claude use my server: read code, run long jobs, pass messages.

Python, talking JSON-RPC, with state in SQLite. Built from 2026-08-22.

It exposes 40 tools. They fall into seven groups.
