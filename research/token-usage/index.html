09 · Case study: a small repository change

A 67-line change to 2 files cost about 4.6M Codex tokens, and about 98% of that was the model re-reading text it had already seen.

The change added written guidance to the instructions Codex gets when it starts a job in a session-tooling repo. Codex wrote and tested it, then Claude reviewed it, amended it, merged it and deployed it.

One thing went wrong. Codex's sandbox had a read-only filesystem, so Codex could not save its change to the repo's history (a "commit"), and Claude had to redo the commit, which took 3 extra tool calls.

For every token Codex wrote, it read 229.

We can't separate out Claude's share, because the same Claude session handled 3 tasks. ChatGPT's share is not measured.

Details

Details: across all 3 tasks the Claude session used about 7.2M tokens, mostly re-reading. That is the most this change could have cost Claude, not an estimate of its actual share. Counts are raw, duplicates removed.
