Wren: our own Claude Duet

Anthropic's Claude Duet checks in each morning and runs long jobs on its own. It asks before sending or paying, and is waitlist-only for now. We had already built most of the same thing from Claude Code and open tools. It runs on our own server. We call it Wren.

How it grew

  • June 2026. Session tooling (crss) lets Claude Code run for days on a server and be reached from a phone.
  • August. A shared message bus lets Claude, Codex, ChatGPT and other agents hand each other work.
  • October. DispatchBench routes each job to the cheapest model. The orchestrator gets a persona, a memory and a name: Wren.
  • 26 October. Multi-agent alerts and a phone approve/deny gate, tested live both ways.

How you talk to it

  • You ask from anywhere. Telegram, the Claude apps or ChatGPT all reach one server and memory. You can run several Wren threads at once.
  • Opus plans and checks; cheaper models do the work. Codex builds, Haiku reads, other agents help over a bus.
  • Files keep the state. Checkpoints, notes and lessons live on disk.
  • You approve orders. A phone gate covers selected other actions.

  • DispatchBench and the delegate skills: the cheapest passing model takes each step. New models plug in; see .

Backups, gbrain and our stance
LayerWhat it doesHow it fails
BackupsWhatCode and key work live in private GitHub repos. Local snapshots before risky changes.FailsStriped disks: one dead drive loses the box. An encrypted off-box copy runs daily (an off-site storage box). Transcripts and Hermes/OpenClaw state: no backup, by choice.

We also run gbrain, a knowledge-base server. Its health check fails and a sync aborted, so nothing depends on it.

Our stance: after a breach we rebuild from scratch and carefully re-pull private repos. We don't trust possibly compromised backups. The encrypted backup holds curated memory and config. The trade-off: unpushed work outside it is lost.

What others do
  • OpenClaw "dreaming": a nightly rewrite of the memory file, backed up first. It appends instead if it would drop over a quarter.
  • Hermes: pluggable memory providers, and a curator that retires unused skills.
  • ChatGPT: saved memories and references to past chats, in your OpenAI account, not in files you can diff.
  • Papers: MemGPT pages memory like an operating system. Reflexion writes lessons after failures.

What we learned

  • Expensive head, cheap hands. The strong model plans and checks; cheaper models do the reading and building.
  • A "done" is a claim. Wren re-runs the check before it believes a helper, and so should you.
  • Borrow openly, then add only what fixes a repeat failure. From Hermes and OpenClaw: persona, lesson hook, what not to remember.
  • Remove scaffolding as models improve. Re-test each hook and rule per model; drop what stops paying.
  • Control the server, control the gates. You decide what runs, where, and what needs your yes first.
