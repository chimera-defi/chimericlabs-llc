The AI tokens behind it

I count tokens, the units AI models read and write. Most are cheap re-reads.

  • A token is about three-quarters of a word.
  • Re-reads cost about a twentieth of fresh input at list prices.
  • I pay flat monthly plans, so this is usage, not a bill.

What the same work would cost at API prices: see "What it costs" in the Wren article

How these numbers were made
  • Commits: git log on each project's main checkout, counted by author month, duplicates removed. Agent Host uses its newest local branch.
  • Claude tokens: 3,473 local session logs, deduplicated per message, audited 2026-10-29.
  • Codex tokens: 3,818 session logs with final counters, audited 2026-10-29. A later check flags these totals as disputed, so treat them as rough.
  • Not counted: ChatGPT chat usage, which has no token meter we can read, and small Grok, Devin and Kimi runs.
  • No invoice-backed dollar total exists yet. That is why the chart shows tokens.
Limits
  • Commit counts include merge commits and agent commits. They measure activity, not value.
  • Early months are partial: some old session logs are gone.
  • One snapshot in time: 2026-10-31.
