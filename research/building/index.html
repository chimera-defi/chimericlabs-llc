The AI tokens behind it

I count tokens, the units AI models read and write. Most are cheap re-reads.

Claude

20.8 billion tokens

Measured from 2026-07-10 to 2026-11-01, with gaps, raw, cache reads included. Earlier logs are gone, so this is a floor, not a lifetime total.

Codex

27.2 billion tokens

Raw tokens Codex used itself on this server, cached input included, 2026-05-24 to 2026-11-01.

Estimates, not a bill. The two tools count differently, so the totals are not added together.

  • A token is about three-quarters of a word.
  • Re-reads cost about a twentieth of fresh input at list prices.
  • I pay flat monthly plans, so this is usage, not a bill.
How these numbers were made
  • Commits: git log --all on every local repo, counted once per commit even across branches, from 2025-10-01 to 2026-11-01. Commits by outside authors are left out. Merge commits and pull-request branch commits both count.
  • Claude tokens: local session logs, deduplicated per message, taking the larger of the 2026-10-29 audit and the daily ledger for each day.
  • Codex tokens: every local session log, counting only each session's own use, not the history it inherited from a parent session.
  • Not counted: ChatGPT chat usage, which has no token meter we can read, and small Grok, Devin and Kimi runs.
  • No invoice-backed dollar total exists yet. That is why the page shows tokens.
Limits
  • Commit counts include merge commits and agent commits. They measure activity, not value.
  • Early months are partial: some old session logs are gone.
  • One snapshot in time: 2026-11-01.
