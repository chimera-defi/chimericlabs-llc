The AI tokens behind it

I count tokens, the units AI models read and write. Most are cheap re-reads.

Claude

18.8 billion tokens

Observed over the same dates for both tools, 2026-09-07 to 2026-11-03 (last day partial). Raw, cache reads included; 3.1 billion tokens from recovered logs are left out.

Codex

6.7 billion tokens

Same dates, 2026-09-07 to 2026-11-03. Raw tokens Codex used itself on this server, cached input included.

Same comparison, shorter windows: last 30 days, Claude 9.5 billion and Codex 4.8 billion; last 7 days, Claude 2.4 billion and Codex 1.9 billion.

Longer ranges, with different start dates, so not comparable: Claude 22.0 billion from 2026-07-10, with gaps (earlier logs are gone, so this is a floor). Codex 27.9 billion from 2026-05-24, 65% of it a July–August spike when Claude logs are missing. Estimates, not a bill. The two tools count differently, so the totals are not added together.

DispatchBench: how we pick which model builds what →

  • A token is about three-quarters of a word.
  • Re-reads cost about a twentieth of fresh input at list prices.
  • I pay flat monthly plans, so this is usage, not a bill.
How these numbers were made
  • Commits: git log --all on every local repo, counted once per commit even across branches, from 2025-10-01 to 2026-11-03. Commits by outside authors are left out. Merge commits and pull-request branch commits both count. Totals can step up between refreshes when a sweep picks up more branches.
  • Claude tokens: local session logs, deduplicated per message, taking the larger of the 2026-10-29 audit and the daily ledger for each day.
  • Codex tokens: every local session log, counting only each session's own use, not the history it inherited from a parent session.
  • Not counted: ChatGPT chat usage, which has no token meter we can read, and small Grok, Devin and Kimi runs.
  • No invoice-backed dollar total exists yet. That is why the page shows tokens.
Limits
  • Commit counts include merge commits and agent commits. They measure activity, not value.
  • Early months are partial: some old session logs are gone.
  • One snapshot in time: 2026-11-03.
